# Garimpo POP — mídia pública

Diretório de imagens publicitárias originais e aprovadas para uso na operação de afiliados Garimpo POP (Mercado Livre).

As imagens são artes tipográficas criadas para publicação com aviso de publicidade. Os preços de anúncios podem mudar. Não contém chaves de API, dados de autenticação nem arquivos de operação.

Este repositório abriga os arquivos estáticos da campanha; a autorização de publicar permanece no CT 103.
